Tech Stack Preference

The ML engine needs Python. The question is what runs the web frontend.

A

Python All-in-One (FastAPI + Jinja/HTMX)

Single Python codebase. FastAPI serves the web UI and runs the ML engine. Simple to deploy, no separate frontend build step. Recommended for a personal tool.

B

Python Backend + React Frontend

FastAPI handles data & ML. React handles the dashboard UI. More polished, richer interactive charts. More complex to set up — two separate processes.

C

Streamlit (Pure Python)

Fastest to build. Python only, auto-generates the UI. Great for data dashboards. Less control over design but gets you running in hours, not days.
