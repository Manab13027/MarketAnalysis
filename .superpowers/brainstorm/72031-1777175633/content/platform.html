What platform should this run on?

This shapes the architecture, deployment, and how you access it daily

A

Web App (Browser)

Access from any device via browser. Easy to deploy, shareable, works on desktop & mobile. Best for a dashboard you check daily.

B

Desktop App (macOS)

Native macOS app. Faster, can run in background, system notifications, offline support. Better for power users who want it always running.

C

Local Web Server + CLI

Run locally on your machine, open in browser. Simplest to build, no deployment needed. Ideal for personal use with full control.
