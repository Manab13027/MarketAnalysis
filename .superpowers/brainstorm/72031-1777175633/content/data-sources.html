Market Data Sources

Where should live index & price data come from? You can pick multiple.

A

Dhan API

Indian indices & stocks — NIFTY, SENSEX, Bank Nifty, SGX Nifty. Requires your Dhan API key. Best for NSE/BSE data.

B

Yahoo Finance (yfinance)

Free, no API key needed. Covers global indices (S&P 500, NASDAQ, DAX, Nikkei, Hang Seng), USDINR, crude oil, MSCI ETFs. Slight delay.

C

NewsAPI / Google News RSS

Free news aggregation for market-moving headlines. Financial news from Reuters, Bloomberg, ET, Moneycontrol, etc.

D

Alpha Vantage / FRED

Free APIs for macro indicators — FII/DII data, VIX, economic calendar. Supplements other sources.
